QUESTIONS & ANSWERS

Frequently Asked Questions

How does CADConvert convert DXF files into vector PDF without rasterization?

Our Java CAD engine compiles native DXF entities—such as lines, arcs, polylines, and NURBS splines—directly into native Adobe PDFBox vector path instructions. The resulting PDF scales infinitely without pixelation.

Which AutoCAD DXF versions are supported?

The converter parses both ASCII and binary DXF files across AutoCAD versions R12, R14, 2000, 2004, 2007, 2010, 2013, and 2018+. It natively evaluates ECS, OCS arbitrary axis vectors, and 3D transforms.

Is my proprietary CAD drawing stored on your server?

No. CADConvert runs a strict 100% in-memory processing pipeline. Drawings are parsed in volatile RAM, converted to vector PDF streams, and immediately reclaimed by garbage collection. Zero files are stored on disk.

Can I convert multiple DXF files in a single batch?

Yes. You can select or drop multiple DXF drawings simultaneously. Once processed, you can download individual vector PDFs or export them all together in a single ZIP package.
