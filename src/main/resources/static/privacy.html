Privacy Policy

Last updated: 16 November 2026

1. Files are processed in memory only

CADConvert processes uploaded DXF, DWG and PDF files in server memory (RAM). We do not save, archive or keep your drawings or the PDFs we generate on disk or in any database.

2. Files are discarded immediately

As soon as the converted PDF has been sent back to your browser or API client, the file data in memory is released and discarded.

3. Transit and infrastructure

All traffic between your browser and CADConvert is encrypted with TLS. Requests pass through Cloudflare and are processed on our Google Cloud servers. Our web server logs record only technical metadata (time, HTTP status, request size and duration) to keep the service reliable. We never log file contents, drawing entities or layer names.

4. Settings stored in your browser

Your conversion preferences (for example hatch mode and preview resolution) are saved in your own browser's local storage so they are remembered next time. They are not sent to us except as part of a conversion request.

5. Third-party resources

Our pages load web fonts from Google Fonts and a ZIP library from cdnjs (Cloudflare). These providers receive standard request information such as your IP address when your browser loads them.

6. Contact

For privacy questions, email support@docconvert.net.
