FORMAT SPECIFICATIONS

DXF vs PDF Overview

Understanding the engineering geometry behind the transformation.

DXF

AutoCAD DXF

Drawing Interchange Format

Standardized CAD file format developed by Autodesk to enable data interoperability between AutoCAD and other engineering programs. Stores coordinate vectors, entity geometries, layers, and blocks.

  • Developer: Autodesk Inc.
  • Type: Vector CAD Drawing
  • MIME Type: image/vnd.dxf
  • Entities: Lines, Arcs, Polylines, Bulges, Splines, Hatches, Text, MText, Dimensions
100% Vector Math
PDF

Portable Document Format

ISO 32000-1 Standard

Universal vector and document format created by Adobe. Provides device-independent representation of drawings with infinite scaling, embedded fonts, and exact print margins.

  • Standard: ISO 32000 (Open)
  • Type: Vector Document & Print Master
  • MIME Type: application/pdf
  • Engine: Apache PDFBox 2.x Clean-Room Native Vector Streams

QUESTIONS & ANSWERS

Frequently Asked Questions

How does CADConvert differ from CloudConvert's DXF tool?

CADConvert uses our proprietary, clean-room Java vector conversion engine. Unlike generic third-party converters, it is 100% self-hosted (zero cloud data leakage), preserves specialized civil/architectural hatch rules (such as egov-edcr municipal zoning patterns), and generates ultra-compact native PDF vector geometry with no raster distortion.

Which AutoCAD DXF versions are supported?

CADConvert parses both ASCII and binary DXF files across AutoCAD versions R12, R14, 2000, 2004, 2007, 2010, 2013, and 2018+. It natively handles 2D and 3D coordinate transformations, ECS (Entity Coordinate Systems), and OCS arbitrary axis vectors.

Can I run this service in Docker or Kubernetes?

Yes! The application runs as a lightweight, zero-dependency Java service packaged in a multi-stage Docker container. It starts in under 200 milliseconds and consumes less than 64MB of base memory.

How are CAD hatch patterns rendered?

Hatch geometries are evaluated using a dynamic rule engine that parses boundary loops, calculates precise clipping paths, and renders standard CAD pattern lines (ANSI31, SOLID, DOTS, etc.) or layer-targeted municipal inspection fills.
